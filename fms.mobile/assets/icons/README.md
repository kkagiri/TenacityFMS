# App Icons

## Source Logo

The source logo is saved in this directory and should be used to generate app icons.

## Required Android Icon Sizes

- mipmap-mdpi: 48x48 px
- mipmap-hdpi: 72x72 px
- mipmap-xhdpi: 96x96 px
- mipmap-xxhdpi: 144x144 px
- mipmap-xxxhdpi: 192x192 px

## Icon Generation

Use the provided PowerShell script `generate-android-icons.ps1` to generate icons automatically.
