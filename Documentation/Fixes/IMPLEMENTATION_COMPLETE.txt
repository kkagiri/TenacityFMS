🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

For Users:
  1. Navigate to TankStock > Fuel Data Comparison
  2. Click "Fuel Refill Data" tab
  3. Set filters (date, site, tank)
  4. Click "Apply" to load data
  5. Edit or delete records (admin only)
  6. Export to Excel if needed

For Developers:
  See QUICK_START_FUEL_REFILL.md for common tasks and tweaks
