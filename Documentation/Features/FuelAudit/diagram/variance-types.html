1. Refuel Variance
✅ IMPLEMENTED
What it measures: Difference between fuel dispensed from pump vs fuel received by vehicle
Refuel Variance = GPS Detected - Manual Recorded
📊
FuelRefill: Manual recorded amount
What pump says was dispensed
🛰️
GpsGateReportEntry: GPS detected refuel
What GPS sensor detected (SOAP Report 212)
📋 Example:
Pump Dispensed: 150.0 L
GPS Detected: 145.0 L
Variance: -5.0 L (5 liters missing!)
🎯 Purpose: Detect dispensing errors, pump theft, calibration issues
📍 Location: FuelComparisonController.cs
2. Consumption Variance
❌ NOT IMPLEMENTED
What it measures: Difference between GPS-measured consumption vs calculated consumption
Consumption Variance = Calculated - GPS Measured

Calculated = Opening + Refilled - Closing
GPS Measured = SUM(daily VehicleConsumption)
📈
VehicleConsumption: Daily GPS consumption
Actual fuel consumed (GPS calculated)
🧮
Formula: Opening + Refilled - Closing
Calculated from fuel levels
📋 Example (7-day period):
Opening: 150.0 L
Refueled: +500.0 L
Closing: 170.0 L
Calculated: 480.0 L
GPS Measured: 490.0 L
Variance: -10.0 L (GPS shows 10L more consumed!)
🎯 Purpose: Detect sensor drift, fuel theft during operation, calibration issues
⚠️ Status: Query exists (GetHistoryConsumptionByVehicleQuery) but not used in wizard
3. System Variance
⚠️ PARTIAL
What it measures: Total system fuel position vs expected based on deliveries and consumption
System Variance = Actual Closing - Expected Closing

Expected = Opening + Deliveries - Consumption
Actual = Tank Readings + Vehicle Dead Stock
🛢️
TankVolumeHistory: Tank readings
Opening, closing, deliveries
🚛
GPS/Estimates: Vehicle dead stock
Fuel in vehicle tanks
📋 Example (Weekly audit):
Opening Position: 30,500 L
+ Deliveries: +50,000 L
- Consumption: -62,000 L
Expected Closing: 18,500 L
Actual Closing: 32,700 L
Variance: +14,200 L (14,200L more than expected!)
🎯 Purpose: Overall audit reconciliation, system-wide theft/loss detection
⚠️ Status: Wizard collects data but doesn't calculate variance
