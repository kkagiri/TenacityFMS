Checklist for Adding a Data Source

 Add constant to WidgetTypeDefinitions.DataSources
 Create metadata factory method
 Register in BuildMetadata()
 Add computation method in MetricCalculationService
 Add time series method in TimeSeriesDataService
 Update IdentifierNormalizer if needed
 Test metric computation
 Test time series generation
 Test widget rendering
 Update frontend metric options
 Document in API documentation
