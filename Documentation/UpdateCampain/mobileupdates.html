🛡️ Security Features

Authorization Required

Every fueling checks: authorized equipment, approved operator, correct location, tank capacity, and budget limits. If any check fails, fueling is blocked and logged.

Location Verification

GPS confirms equipment and operator locations. Site geofencing ensures fueling only in designated areas.

Tank Overfill Prevention

System knows each vehicle's tank capacity and current level. Automatically limits authorization to available space.

Daily & Monthly Limits

Set fuel budgets per equipment with automatic enforcement. Limits reset daily and monthly.

📱 Mobile Application

Fuel anywhere on site with full security. The mobile app guides operators through a 9-step secure process:

  • Select tank, pump, and nozzle
  • Scan or search for equipment
  • Review limits and restrictions
  • Authorize and monitor live progress
  • Complete with transaction summary

Offline Capability: App caches essential data for areas with poor connectivity.
