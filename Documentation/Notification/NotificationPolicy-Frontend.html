📋 NotificationPolicy Frontend Implementation Guide

Complete guide for implementing NotificationPolicy management in React frontend

🎯 Implementation Overview

  • Policy Management UI - Create, edit, delete notification policies
  • JSON Field Editors - Advanced configuration for rules and conditions
  • Form Validation - Real-time validation with error feedback
  • Template Editor - Rich text editing for notification templates
  • Preview System - Live preview of policy effects
  • Site & Device Scoping - Context-aware policy management

📊 NotificationPolicy Entity Structure

Core Properties

Property Type Required Description Frontend Component
Name String ✅ Policy identification name TextBox with validation
Description String? ❌ Policy description TextArea
IsActive Boolean ❌ Policy activation status CheckBox/Switch
NotificationCategoryId Integer ✅ Category reference SelectBox
NotificationType String ✅ Type of notification SelectBox
Priority String ✅ Priority level SelectBox

Rate Limiting & Control Properties

Property Type Description Frontend Component Validation
MaxNotificationsPerHour Integer Hourly limit (0 = unlimited) NumberBox with special handling for 0 ≥ 0
MaxNotificationsPerDay Integer Daily limit (0 = unlimited) NumberBox with special handling for 0 ≥ 0
CooldownMinutes Integer Cooldown between similar notifications NumberBox with time unit selector ≥ 0

Delivery Method Properties

Property Type Description Frontend Component
EnableEmail Boolean Enable email notifications CheckBox
EnableSms Boolean Enable SMS notifications CheckBox
EnableSystem Boolean Enable in-app notifications CheckBox
EnableSound Boolean Enable sound alerts CheckBox with sound file selector
SoundFile String? Sound file path/identifier FileUploader + Audio preview

JSON Configuration Properties

Property Type Description Frontend Component
EscalationRules JSON Auto-escalation configuration JsonEditor with escalation wizard
TriggerConditions JSON When to trigger notifications JsonEditor with condition builder
RecipientRules JSON Who receives notifications JsonEditor with recipient selector
ScheduleConfiguration JSON When notifications can be sent Schedule picker with timezone support

import React, { useState, useEffect } from 'react';
import { Form, TextBox, TextArea, CheckBox, SelectBox, NumberBox } from 'devextreme-react';
import { Validator, RequiredRule, StringLengthRule, RangeRule } from 'devextreme-react/validator';
import { JsonConfigSection } from './JsonConfigSection';
import { TemplateEditor } from './TemplateEditor';
import { DeliveryMethodsSection } from './DeliveryMethodsSection';

const NotificationPolicyForm = ({ policy, onSave, onCancel, isEditing = false }) => {
    const [formData, setFormData] = useState({
        name: '',
        description: '',
        isActive: true,
        notificationCategoryId: null,
        notificationType: '',
        priority: 'Medium',
        maxNotificationsPerHour: 0,
        maxNotificationsPerDay: 0,
        cooldownMinutes: 0,
        enableEmail: true,
        enableSms: false,
        enableSystem: true,
        enableSound: false,
        soundFile: null,
        escalationRules: null,
        triggerConditions: null,
        recipientRules: null,
        scheduleConfiguration: null,
        siteId: null,
        ptsDeviceId: null,
        titleTemplate: '',
        messageTemplate: '',
        emailTemplate: '',
        smsTemplate: '',
        requireAcknowledgment: false,
        acknowledgmentTimeoutMinutes: 0,
        createIssueTracker: false,
        ...policy
    });

    const notificationTypes = [
        { value: 'Alert', text: 'Alert' },
        { value: 'Warning', text: 'Warning' },
        { value: 'Info', text: 'Information' },
        { value: 'Critical', text: 'Critical' }
    ];

    const priorityOptions = [
        { value: 'Low', text: 'Low' },
        { value: 'Medium', text: 'Medium' },
        { value: 'High', text: 'High' },
        { value: 'Critical', text: 'Critical' }
    ];

    const handleFieldChange = (field, value) => {
        setFormData(prev => ({
            ...prev,
            [field]: value
        }));
    };

    const handleSubmit = () => {
        // Validation and submission logic
        onSave(formData);
    };

    return (
        <div className="notification-policy-form">
            <Form formData={formData} onFieldDataChanged={handleFieldChange}>

                {/* Basic Information Section */}
                <div className="form-section">
                    <h3>Basic Information</h3>

                    <TextBox
                        label="Policy Name"
                        value={formData.name}
                        onValueChanged={(e) => handleFieldChange('name', e.value)}
                    >
                        <Validator>
                            <RequiredRule message="Policy name is required" />
                            <StringLengthRule max={100} message="Name cannot exceed 100 characters" />
                        </Validator>
                    </TextBox>

                    <TextArea
                        label="Description"
                        value={formData.description}
                        onValueChanged={(e) => handleFieldChange('description', e.value)}
                        maxLength={500}
                    />

                    <CheckBox
                        text="Active"
                        value={formData.isActive}
                        onValueChanged={(e) => handleFieldChange('isActive', e.value)}
                    />
                </div>

                {/* Delivery Methods Section */}
                <DeliveryMethodsSection
                    formData={formData}
                    onFieldChange={handleFieldChange}
                />

                {/* JSON Configuration Section */}
                <JsonConfigSection
                    formData={formData}
                    onFieldChange={handleFieldChange}
                />

                {/* Form Actions */}
                <div className="form-actions">
                    <Button text="Save" type="default" onClick={handleSubmit} />
                    <Button text="Cancel" onClick={onCancel} />
                </div>
            </Form>
        </div>
    );
};

2JsonConfigSection Component

import React, { useState } from 'react';
import { Accordion } from 'devextreme-react/accordion';
import { JsonEditor } from './JsonEditor';
import { EscalationRulesWizard } from './EscalationRulesWizard';
import { TriggerConditionsBuilder } from './TriggerConditionsBuilder';
import { RecipientRulesBuilder } from './RecipientRulesBuilder';
import { ScheduleConfigBuilder } from './ScheduleConfigBuilder';

const JsonConfigSection = ({ formData, onFieldChange }) => {
    const [activeEditor, setActiveEditor] = useState(null);

    const jsonFields = [
        {
            key: 'escalationRules',
            title: 'Escalation Rules',
            description: 'Configure automatic escalation when notifications are not acknowledged',
            wizardComponent: EscalationRulesWizard,
            schema: {
                type: 'object',
                properties: {
                    escalationLevels: {
                        type: 'array',
                        items: {
                            type: 'object',
                            properties: {
                                level: { type: 'number' },
                                delayMinutes: { type: 'number' },
                                recipients: { type: 'array', items: { type: 'string' } }
                            }
                        }
                    }
                }
            }
        },
        {
            key: 'triggerConditions',
            title: 'Trigger Conditions',
            description: 'Define when this policy should trigger notifications',
            wizardComponent: TriggerConditionsBuilder,
            schema: {
                type: 'object',
                properties: {
                    timeConditions: { type: 'object' },
                    frequencyLimit: { type: 'object' },
                    businessRules: { type: 'object' }
                }
            }
        },
        {
            key: 'recipientRules',
            title: 'Recipient Rules',
            description: 'Define who should receive notifications from this policy',
            wizardComponent: RecipientRulesBuilder,
            schema: {
                type: 'object',
                properties: {
                    rules: {
                        type: 'array',
                        items: {
                            type: 'object',
                            properties: {
                                condition: { type: 'string' },
                                recipients: { type: 'array', items: { type: 'string' } }
                            }
                        }
                    }
                }
            }
        },
        {
            key: 'scheduleConfiguration',
            title: 'Schedule Configuration',
            description: 'Control when notifications can be sent',
            wizardComponent: ScheduleConfigBuilder,
            schema: {
                type: 'object',
                properties: {
                    businessHours: { type: 'object' },
                    timezone: { type: 'string' },
                    blackoutPeriods: { type: 'array' }
                }
            }
        }
    ];

    const handleJsonChange = (field, value) => {
        try {
            const parsed = typeof value === 'string' ? JSON.parse(value) : value;
            onFieldChange(field, JSON.stringify(parsed));
        } catch (error) {
            // Handle JSON parsing errors
            console.error('Invalid JSON:', error);
        }
    };

    return (
        <div className="json-config-section">
            <h3>Advanced Configuration</h3>

            <Accordion>
                {jsonFields.map(field => (
                    <div key={field.key} title={field.title}>
                        <p>{field.description}</p>

                        <div className="json-editor-container">
                            <div className="editor-tabs">
                                <button
                                    className={activeEditor === `${field.key}-wizard` ? 'active' : ''}
                                    onClick={() => setActiveEditor(`${field.key}-wizard`)}
                                >
                                    Wizard
                                </button>
                                <button
                                    className={activeEditor === `${field.key}-json` ? 'active' : ''}
                                    onClick={() => setActiveEditor(`${field.key}-json`)}
                                >
                                    JSON Editor
                                </button>
                            </div>

                            {activeEditor === `${field.key}-wizard` ? (
                                <field.wizardComponent
                                    value={formData[field.key] ? JSON.parse(formData[field.key]) : {}}
                                    onChange={(value) => handleJsonChange(field.key, value)}
                                />
                            ) : (
                                <JsonEditor
                                    value={formData[field.key] || '{}'}
                                    schema={field.schema}
                                    onChange={(value) => handleJsonChange(field.key, value)}
                                />
                            )}
                        </div>
                    </div>
                ))}
            </Accordion>
        </div>
    );
};

3PolicyList Component with Filtering

import React, { useState, useEffect } from 'react';
import { DataGrid } from 'devextreme-react/data-grid';
import { Column, Paging, FilterRow, HeaderFilter, Pager } from 'devextreme-react/data-grid';
import { Button } from 'devextreme-react/button';
import { Popup } from 'devextreme-react/popup';
import { NotificationPolicyForm } from './NotificationPolicyForm';

const PolicyList = () => {
    const [policies, setPolicies] = useState([]);
    const [selectedPolicy, setSelectedPolicy] = useState(null);
    const [isFormVisible, setIsFormVisible] = useState(false);
    const [isEditing, setIsEditing] = useState(false);
    const [loading, setLoading] = useState(false);

    useEffect(() => {
        loadPolicies();
    }, []);

    const loadPolicies = async () => {
        setLoading(true);
        try {
            const response = await fetch('/api/notification/policies');
            const data = await response.json();
            setPolicies(data);
        } catch (error) {
            console.error('Error loading policies:', error);
        } finally {
            setLoading(false);
        }
    };

    const handleCreate = () => {
        setSelectedPolicy(null);
        setIsEditing(false);
        setIsFormVisible(true);
    };

    const handleEdit = (policy) => {
        setSelectedPolicy(policy);
        setIsEditing(true);
        setIsFormVisible(true);
    };

    const handleDelete = async (policyId) => {
        if (confirm('Are you sure you want to delete this policy?')) {
            try {
                await fetch(`/api/notification/policies/${policyId}`, {
                    method: 'DELETE'
                });
                loadPolicies();
            } catch (error) {
                console.error('Error deleting policy:', error);
            }
        }
    };

    const handleSave = async (policyData) => {
        try {
            const url = isEditing
                ? `/api/notification/policies/${selectedPolicy.id}`
                : '/api/notification/policies';

            const method = isEditing ? 'PUT' : 'POST';

            await fetch(url, {
                method,
                headers: {
                    'Content-Type': 'application/json'
                },
                body: JSON.stringify(policyData)
            });

            setIsFormVisible(false);
            loadPolicies();
        } catch (error) {
            console.error('Error saving policy:', error);
        }
    };

    const renderActionColumn = (cellData) => {
        return (
            <div className="action-buttons">
                <Button
                    icon="edit"
                    hint="Edit"
                    onClick={() => handleEdit(cellData.data)}
                />
                <Button
                    icon="trash"
                    hint="Delete"
                    onClick={() => handleDelete(cellData.data.id)}
                />
            </div>
        );
    };

    return (
        <div className="policy-list">
            <div className="list-header">
                <h2>Notification Policies</h2>
                <Button
                    text="Create Policy"
                    type="default"
                    icon="plus"
                    onClick={handleCreate}
                />
            </div>

            <DataGrid
                dataSource={policies}
                showBorders={true}
                remoteOperations={false}
                allowColumnReordering={true}
                allowColumnResizing={true}
                columnAutoWidth={true}
                loading={loading}
            >
                <FilterRow visible={true} />
                <HeaderFilter visible={true} />
                <Paging defaultPageSize={20} />
                <Pager showPageSizeSelector={true} />

                <Column dataField="name" caption="Name" width={200} />
                <Column dataField="description" caption="Description" />
                <Column dataField="notificationType" caption="Type" width={120} />
                <Column dataField="priority" caption="Priority" width={100} />
                <Column
                    dataField="isActive"
                    caption="Status"
                    width={80}
                    cellRender={(cellData) => cellData.value ? 'Active' : 'Inactive'}
                />
                <Column
                    dataField="createdAt"
                    caption="Created"
                    dataType="datetime"
                    width={120}
                />
                <Column
                    caption="Actions"
                    width={120}
                    cellRender={renderActionColumn}
                    allowSorting={false}
                    allowFiltering={false}
                />
            </DataGrid>

            <Popup
                visible={isFormVisible}
                onHiding={() => setIsFormVisible(false)}
                dragEnabled={false}
                closeOnOutsideClick={false}
                showTitle={true}
                title={isEditing ? 'Edit Policy' : 'Create Policy'}
                width="90%"
                height="90%"
            >
                <NotificationPolicyForm
                    policy={selectedPolicy}
                    onSave={handleSave}
                    onCancel={() => setIsFormVisible(false)}
                    isEditing={isEditing}
                />
            </Popup>
        </div>
    );
};

🔧 JSON Field Wizards

Escalation Rules Wizard

const EscalationRulesWizard = ({ value, onChange }) => {
    const [escalationLevels, setEscalationLevels] = useState(
        value?.escalationLevels || []
    );

    const addEscalationLevel = () => {
        const newLevel = {
            level: escalationLevels.length + 1,
            delayMinutes: 15,
            recipients: []
        };
        const updated = [...escalationLevels, newLevel];
        setEscalationLevels(updated);
        onChange({ escalationLevels: updated });
    };

    const removeEscalationLevel = (index) => {
        const updated = escalationLevels.filter((_, i) => i !== index);
        setEscalationLevels(updated);
        onChange({ escalationLevels: updated });
    };

    const updateLevel = (index, field, value) => {
        const updated = escalationLevels.map((level, i) =>
            i === index ? { ...level, [field]: value } : level
        );
        setEscalationLevels(updated);
        onChange({ escalationLevels: updated });
    };

    return (
        <div className="escalation-wizard">
            <h4>Escalation Levels</h4>

            {escalationLevels.map((level, index) => (
                <div key={index} className="escalation-level">
                    <div className="level-header">
                        <h5>Level {level.level}</h5>
                        <Button
                            icon="trash"
                            onClick={() => removeEscalationLevel(index)}
                        />
                    </div>

                    <NumberBox
                        label="Delay (minutes)"
                        value={level.delayMinutes}
                        onValueChanged={(e) => updateLevel(index, 'delayMinutes', e.value)}
                    />

                    <TagBox
                        label="Recipients"
                        value={level.recipients}
                        dataSource={availableRecipients}
                        displayExpr="name"
                        valueExpr="email"
                        onValueChanged={(e) => updateLevel(index, 'recipients', e.value)}
                        searchEnabled={true}
                    />
                </div>
            ))}

            <Button
                text="Add Escalation Level"
                icon="plus"
                onClick={addEscalationLevel}
            />
        </div>
    );
};

🔍 Policy Preview System

Live Policy Preview

const PolicyPreview = ({ policyData, siteId }) => {
    const [previewData, setPreviewData] = useState(null);
    const [loading, setLoading] = useState(false);

    const generatePreview = async () => {
        setLoading(true);
        try {
            const response = await fetch('/api/notification/policies/preview', {
                method: 'POST',
                headers: { 'Content-Type': 'application/json' },
                body: JSON.stringify({ ...policyData, siteId })
            });
            const data = await response.json();
            setPreviewData(data);
        } catch (error) {
            console.error('Error generating preview:', error);
        } finally {
            setLoading(false);
        }
    };

    useEffect(() => {
        if (policyData) {
            generatePreview();
        }
    }, [policyData, siteId]);

    return (
        <div className="policy-preview">
            <h3>Policy Preview</h3>

            {loading && <div className="loading">Generating preview...</div>}

            {previewData && (
                <div className="preview-content">
                    <div className="preview-section">
                        <h4>Affected Recipients</h4>
                        <div className="recipient-count">
                            {previewData.recipientCount} users will receive notifications
                        </div>
                        <div className="recipient-breakdown">
                            <div>Email: {previewData.emailRecipients}</div>
                            <div>SMS: {previewData.smsRecipients}</div>
                            <div>System: {previewData.systemRecipients}</div>
                        </div>
                    </div>

                    <div className="preview-section">
                        <h4>Sample Notification</h4>
                        <div className="notification-sample">
                            <div className="sample-title">{previewData.sampleTitle}</div>
                            <div className="sample-message">{previewData.sampleMessage}</div>
                        </div>
                    </div>

                    <div className="preview-section">
                        <h4>Rate Limiting Impact</h4>
                        <div className="rate-info">
                            <div>Max hourly notifications: {policyData.maxNotificationsPerHour || 'Unlimited'}</div>
                            <div>Cooldown period: {policyData.cooldownMinutes || 0} minutes</div>
                        </div>
                    </div>
                </div>
            )}
        </div>
    );
};

🔌 API Integration

API Service Layer

// notificationPolicyService.js
class NotificationPolicyService {
    baseUrl = '/api/notification/policies';

    async getAll(siteId = null) {
        const url = siteId ? `${this.baseUrl}?siteId=${siteId}` : this.baseUrl;
        const response = await fetch(url);
        return await response.json();
    }

    async getById(id) {
        const response = await fetch(`${this.baseUrl}/${id}`);
        return await response.json();
    }

    async create(policyData) {
        const response = await fetch(this.baseUrl, {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify(policyData)
        });
        return await response.json();
    }

    async update(id, policyData) {
        const response = await fetch(`${this.baseUrl}/${id}`, {
            method: 'PUT',
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify(policyData)
        });
        return await response.json();
    }

    async delete(id) {
        const response = await fetch(`${this.baseUrl}/${id}`, {
            method: 'DELETE'
        });
        return response.ok;
    }

    async preview(policyData, siteId = null) {
        const response = await fetch(`${this.baseUrl}/preview`, {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify({ ...policyData, siteId })
        });
        return await response.json();
    }

    async testPolicy(policyId, testData) {
        const response = await fetch(`${this.baseUrl}/${policyId}/test`, {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify(testData)
        });
        return await response.json();
    }

    async getCategories() {
        const response = await fetch('/api/notification/categories');
        return await response.json();
    }

    async getRecipients(siteId = null) {
        const url = siteId
            ? `/api/notification/recipients?siteId=${siteId}`
            : '/api/notification/recipients';
        const response = await fetch(url);
        return await response.json();
    }
}

export const notificationPolicyService = new NotificationPolicyService();

Form Validation Rules

Name: Required, max 100 characters, must be unique within site scope
Description: Optional, max 500 characters
NotificationCategoryId: Required, must exist in system
NotificationType: Required, must be valid enum value
Rate Limits: Must be >= 0, reasonable limits to prevent spam
JSON Fields: Must be valid JSON, conform to schemas
Templates: Variable syntax validation, length limits
