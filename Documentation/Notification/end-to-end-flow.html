🔧 Common Issues & Troubleshooting

❌ No Notifications Sent

  • Check AlarmHandler.IsActive = true
  • Verify AlarmHandler.TriggerConditions match incoming data
  • Check NotificationPolicy.TriggerConditions (business hours, frequency limits)
  • Verify cooldown period hasn't blocked the notification
  • Check daily limit hasn't been exceeded
  • ActiveAlarm Issues: Check if ActiveAlarm.SuppressNotifications = false
  • PTS Integration: Verify PTS alert states are correctly processed

❌ ActiveAlarm Duplication

  • Check Redis deduplication cooldown (5-minute periods)
  • Verify alarm identifier uniqueness logic
  • Check PTS alert state processing ("Started", "Detected", "Finished")
  • Monitor UploadAlertRecordHandler error logs

❌ Wrong Recipients

  • Check NotificationPolicy.RecipientRules JSON syntax
  • Verify PolicyRecipients table has active recipients
  • Check user notification preferences
  • Verify delivery method availability (email, phone, etc.)

✅ Monitoring & Validation

  • Use AlarmHandlerExecution table to track trigger attempts
  • Monitor NotificationRecipient.DeliveryStatus for delivery tracking
  • Check PolicyRulesProcessor logs for JSON rule evaluation
  • Use TriggerEvaluationTester frontend component for testing
  • ActiveAlarm Monitoring: Check ActiveAlarm state transitions in database
  • Dashboard Validation: Verify alarm display across modules (main, tank, PTS)
  • PTS Integration: Monitor UploadAlertRecordHandler processing logs
  • Auto-Resolution: Track automatic resolution on "Finished" PTS states
