sequenceDiagram
    participant MU as Mobile User
    participant C as PumpController
    participant PS as PumpService
    participant CE as CommandExecutor
    participant DCS as DeviceCommunicationService
    participant PCR as PendingCommandRepo
    participant CM as ConnectionManager/WebSocket
    participant HP as HTTPPusher
    participant D as Device(PTS-2)
    participant USH as UploadStatusHandler
    participant M as Mediator(UploadStatusCommand)
    participant AMS as Automated Monitor Scenario

    rect rgb(200,230,255)
    note over MU: User triggers pump authorization via /pump/authorize
    MU->>C: POST /pump/authorize {DeviceId, PumpAuthorizeData}
    C->>PS: AuthorizePumpAsync(DeviceId, PumpAuthorizeData)
    PS->>CE: ExecuteCommandAsync("PumpAuthorizeCommand", PumpAuthorizeData)
    CE->>DCS: CanPushCommandsToDevice(DeviceId)
    DCS->>DCS: Validate device, check mode
    alt WebSocket Available (Blue)
        DCS->>CE: canPush = true, mode = WebSocket
        CE->>CM: Send command via WebSocket
        CM->>D: Device receives PumpAuthorizeCommand
    else HTTP direct IP (Green)
        DCS->>CE: canPush = true, mode = Http
        CE->>HP: Send command via direct HTTP
        HP->>D: Device receives PumpAuthorizeCommand immediately
    else Polling (Red)
        DCS->>CE: canPush = false
        CE->>PCR: SavePendingConfigurationAsync
    end

    CE->>PS: CommandResult Success/OK
    PS->>C: return Ok with message
    C->>MU: Pump authorized command processed
    end

    rect rgb(255,240,240)
    note over D: Device uploads status later (polling scenario)
    D->>USH: POST /jsonPTS/uploadStatus (request)
    USH->>M: Send(UploadStatusCommand)
    M->>PCR: Check for pending commands
    alt Pending commands (Red)
        PCR->>M: Return pending command
        M->>USH: Return CommandResult with SetRequestType/Data
    else No pending commands
        M->>USH: Return CommandResult OK
    end

    note over USH: Automated logic detects nozzle lift
    USH->>PS: AuthorizePumpAsync(DeviceId, derivedPumpData)
    PS->>CE: ExecuteCommandAsync("PumpAuthorizeCommand", derivedPumpData)
    CE->>DCS: CanPushCommandsToDevice(DeviceId)?
    alt canPush now (Blue or Green)
        CE->>CM or HP: Push command immediately
        D->>D: Device reacts immediately
    else must wait (Red)
        CE->>PCR: SavePendingConfigurationAsync
    end

    USH->>D: Respond with UploadStatus + any pending commands
    D->>D: If any commands included, execute now
    end
