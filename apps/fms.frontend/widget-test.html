🧪 Widget Testing Dashboard

Comprehensive testing environment for all dashboard widgets with mock data

🚀 How to Test Your Widgets

  1. Navigate to fms.frontend/src/components/dashboard/
  2. Import the WidgetTestPage component: import WidgetTestPage from './WidgetTestPage';
  3. Add it to your router or render it directly in your app
  4. Each widget will be displayed with appropriate mock data for testing
